# Hospital ER Operations Analytics Dashboard | Tableau

## Project Overview

The Hospital ER Operations Analytics Dashboard is an interactive Tableau project designed to analyze emergency room operations, patient demographics, department performance, and resource utilization.

The project contains three dashboards that transform hospital data into meaningful insights and support data-driven decision-making.

## Project Objectives

- Analyze patient volume and admission patterns.
- Understand patient demographics and diagnoses.
- Evaluate waiting time and treatment time.
- Monitor patient outcomes and satisfaction.
- Analyze bed occupancy and readmission rates.
- Identify monthly trends in patient volume and waiting time.

## Tools & Technologies

- Tableau
- Microsoft Excel
- Data Visualization
- KPI Analysis
- Exploratory Data Analysis
